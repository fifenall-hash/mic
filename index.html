📘 GitHub 무료 홈페이지 배포 가이드

  1. GitHub 저장소(Repository) 생성: GitHub에 로그인 후 새 Public 저장소를 만듭니다.
  2. 파일 업로드: 이 코드 파일을 index.html 이름으로 저장소 루트에 업로드(Commit)합니다.
  3. GitHub Pages 활성화: 저장소의 Settings → Pages 메뉴에서 Branch를 main으로 선택하고 Save를 누릅니다.
  4. 자동 글로벌 월드 공유: 생성된 https://아이디.github.io/저장소명/ 링크에 접속하는 모든 사람은 별도의 방 코드 없이도 자동으로 하나의 공유 월드(X:500, Y:500 광장)에서 즉시 만나 함께 채굴하고 건축할 수 있습니다!
